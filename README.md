# Gabcel App - Legal Documentation Package

## Overview

This folder contains two essential legal documents required for publishing the Gabcel hire purchase app on the Google Play Store. These documents establish your legal framework and protect both your company and your users.

---

## 📄 Documents Included

### 1. **Privacy Policy** (`privacy-policy.html`)

A comprehensive privacy policy that details how the Gabcel App collects, uses, and protects user data.

**Key Sections:**

- Information collection practices (user accounts, customer data, transactions, GPS, device info)
- Data usage purposes (transaction processing, analytics, security, legal compliance)
- GPS location and timestamp tracking details
- National ID and identity information protection
- Payment information security
- Data sharing policies
- Security measures and user responsibilities
- Data retention periods
- User rights (access, correction, deletion, portability)
- Contact information for privacy inquiries
- Data deletion and retention procedures

**Play Store Requirements Met:**
✓ Transparent data collection disclosures
✓ Legal basis for data processing
✓ Third-party sharing details
✓ User rights and choices
✓ Data security measures
✓ Contact information for privacy concerns
✓ Compliance with GDPR/CCPA-style privacy regulations

- [ ] **Privacy Policy Link** - Add the privacy policy URL to your Play Store listing

## 🚀 Publishing Steps

### Step 1: Hosting the Documents

```
1. Upload privacy-policy.html to: https://yourdomain.com/legal/privacy-policy.html
2. Upload terms-of-use.html to: https://yourdomain.com/legal/terms-of-use.html
3. Test links for accessibility
```

### Step 2: Update Your Play Store Listing

```
1. Open Google Play Developer Console
2. Navigate to App → Store Listing
3. Add Privacy Policy URL
4. Add Support Email
5. Add Support Phone Number
6. Save and review
```

### Step 3: Configure Data Safety Section

```
1. Go to Data Safety section in Developer Console
2. Click "Start disclosure" or "Edit"
3. Answer data collection questions:
   - Yes, you collect personal data (names, IDs, phone numbers, addresses)
   - Yes, you collect GPS and location data
   - Yes, you collect device identifiers
   - Yes, data is encrypted in transit and at rest
4. Indicate data is retained for hire purchase contract duration + 7 years
5. Confirm no data is sold to third parties
```

### Step 4: Set App Age & Content Rating

```
1. Complete Content Rating Questionnaire
2. Select business/productivity category
3. Mark as not intended for children
4. Indicate business to employee communication
```

### Step 5: Final Review

```
1. Review all linked documents for accuracy
2. Test document accessibility on Play Store
3. Verify all placeholders are updated
4. Confirm legal review by your company attorney
5. Submit app review
```
